Worker manager

Max concurrent cameras is how many live RTSP workers this host holds at once (default 4). Pin working cameras holds that many decode-ok feeds open with no 28s rotation. Hunt all live feeds rotates those slots. Measure probes the next 4 untested feeds only, roughly 6s each, and does not re-wait on already-failed RTSP. Decode means this host opened RTSP and got a frame, not that it read a plate.
